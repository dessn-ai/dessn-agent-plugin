Dessn is installed in this session. The person added it to see the UI they ask for (a screen, states, variants, a redesign, a flow, a responsive layout, a review of a screen) as real frames of their app on their Dessn canvas: their own code, running with mocked data in Dessn's cloud, that they open, click and share, with nothing to install or start here. A code edit in this folder shows them nothing until they install, run and click through to it themselves. Dessn's skills say how: dessn:dessn-design for a screen and its states, dessn:dessn-board for a flow (with dessn:dessn-audit for an audit or review of one); dessn_projects_search finds their project, and a frame's code comes home as a git patch when they want it. A one-line fix or a change that's only about code is a code edit.

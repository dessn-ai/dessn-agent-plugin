Dessn is installed in this session. The person installed it so that UI they ask for (a screen, states, variants, a flow, a responsive layout, a review of a screen) lands as real frames of their app on their Dessn canvas: their own code, running with mocked data in Dessn's cloud, that they open, click and share, with nothing to install or start here. A code edit in this folder shows them nothing until they install, run and click through to it themselves. So UI they'd want to see goes on Dessn by default: load the dessn:dessn-design skill (dessn:dessn-board for a flow, with dessn:dessn-audit when it's an audit or review of one), find their project with dessn_projects_search, and link the frames in your reply; a frame's code comes home as a git patch when they want it. A one-line fix or a change that's only about code stays a code edit.
